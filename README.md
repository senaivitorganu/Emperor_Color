# 👑 Emperor Color

## O que é?

**Emperor Color** é um jogo 2D desenvolvido na Unity em estilo **Pixel Art**. O projeto foi criado com o objetivo de proporcionar uma experiência de desafio e aventura, onde o jogador utiliza seus poderes para devolver as cores a um mundo que perdeu toda a sua vida e alegria.

---

## História do jogo

Após um misterioso acontecimento, um reino inteiro perdeu todas as suas cores, transformando-se em um mundo preto e branco. Para restaurar a esperança desse lugar, um rei vindo de outra dimensão é convocado para cumprir uma missão: devolver suas cores utilizando seus poderes mágicos.

Durante a jornada, enfrentar desafios e colorir o mundo novamente, trazendo vida e beleza para cada região visitada.

---
